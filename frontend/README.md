# Servicios Bancarios - Frontend

Frontend en React para el sistema de servicios bancarios.

## Tecnologías
- React 19 + Vite
- React Router DOM
- Lucide React (iconos)
- XMLHttpRequest (para peticiones HTTP)

## Scripts
- `npm run dev`: Inicia servidor de desarrollo
- `npm run build`: Construye para producción
- `npm test`: Ejecuta tests con Vitest

## Estructura
- `src/pages`: Páginas (Login, Dashboard, Transacciones, etc.)
- `src/components`: Componentes reutilizables
- `src/context`: Contextos (Auth)
